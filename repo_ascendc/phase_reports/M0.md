## Changes

- Markdown is represented as headings, paragraphs, tables, code candidates, constraints, and examples.
- Parsing retains source URL, document ID, source path, and SHA-256 without inferring hardware semantics.
- Parameter facts retain the exact table-row evidence and section ID.
- No planner, generator, evaluator, runtime router, or source-validator behavior changed.
